{% trans "How do I get a QGIS account?" %}

{% blocktrans trimmed %} Somebody invites you. There is no sign up form, and having an account on another QGIS site is not enough on its own. Every account here exists because a named person vouched for it. That is what lets us give contributors real editing rights without knowing everybody personally. {% endblocktrans %}

{% blocktrans trimmed %} So ask someone who already writes for the feed, or ask a feed maintainer. They create the account and send you a link. {% endblocktrans %}

{% trans "Someone sent me a link. What do I do?" %}

{% blocktrans trimmed %} The link signs you in once, so that you can set the account up. Treat it like a password and do not pass it on. {% endblocktrans %}

  1. {% blocktrans trimmed %} Open the link on the device you want to sign in with from now on. Your phone or your laptop both work. {% endblocktrans %}
  2. {% trans "Confirm your email address when you are asked to." %}
  3. {% trans "Create a passkey. Your device will offer to do this for you." %}

{% blocktrans trimmed %} That is it. From then on you sign in with the passkey and the link is finished. If the link has expired, ask for a fresh one. {% endblocktrans %}

{% trans "What is a passkey?" %}

{% blocktrans trimmed %} A passkey lets your device prove who you are, using the same face scan, fingerprint or screen lock you already use to unlock it. There is no password on your QGIS account at all. {% endblocktrans %}

{% blocktrans trimmed %} This is safer and quicker. There is no password to forget, to reuse, or for somebody to steal, and a passkey cannot be handed over to a fake sign in page by mistake. {% endblocktrans %}

{% blocktrans trimmed %} A passkey can live on your phone, your laptop, or a hardware key you plug in. Keep at least two, on two different devices. Losing your only passkey means losing your way in. {% endblocktrans %}

{% trans "How do I add a passkey?" %}

  1. {% blocktrans trimmed %} Open Your account from the menu under your name. {% endblocktrans %}
  2. {% trans "Choose Add a passkey." %}
  3. {% blocktrans trimmed %} Sign in as usual, then follow what your device asks. The new passkey belongs to whichever device you are using at that moment, so use the one you want to add. {% endblocktrans %}

{% trans "How do I remove a passkey?" %}

{% blocktrans trimmed %} Open Your account, find the passkey in the list, and choose the remove button beside it. {% endblocktrans %}

{% blocktrans trimmed %} You cannot remove your last passkey. There is no password to fall back on, so it would lock you out. Add a second one first, then remove the one you no longer want. {% endblocktrans %}

{% trans "I have lost the device with my passkey" %}

{% blocktrans trimmed %} Sign in with one of your other passkeys, open Your account, and remove the one on the lost device. Do this even if the device was locked. {% endblocktrans %}

{% blocktrans trimmed %} If that was your only passkey, you cannot get in by yourself. Ask a feed maintainer for a new enrolment link and set the account up again. {% endblocktrans %}

{% trans "Who can I invite?" %}

{% blocktrans trimmed %} People at your own level or below, never above. You cannot hand out more than you hold, which is what stops the chain of trust being climbed. {% endblocktrans %}

{% blocktrans trimmed %} There is also a limit on how many invitations you can have open at once. An invitation counts as open until the person signs in for the first time. When they do, the place frees up and you can invite somebody else. {% endblocktrans %}

{% trans "How do I invite someone?" %}

  1. {% trans "Open People from the menu under your name." %}
  2. {% trans "Choose Invite, then New user." %}
  3. {% blocktrans trimmed %} Fill in their name, their email address and the role you are giving them. The account is created straight away. Nothing is sent yet. {% endblocktrans %}
  4. {% blocktrans trimmed %} Send them the setup email, or take the enrolment link and hand it over yourself. The link is shown once and is never stored, so copy it before you leave the page. {% endblocktrans %}
{% blocktrans trimmed %} The link signs its holder in as that person. Give it to them and nobody else, the way you would a password. If you are in the same room, the QR code beside it is the safest way to pass it over. {% endblocktrans %}

{% blocktrans trimmed %} You are vouching for them. If they misuse the account, that reflects on you, and withdrawing trust from you reaches them too. {% endblocktrans %}

{% trans "What happens if trust is withdrawn?" %}

{% blocktrans trimmed %} Trust is withdrawn when somebody should no longer have access, for example when they leave a role or an account is misused. It is a deliberate act by a maintainer, with a reason recorded. {% endblocktrans %}

  • {% trans "That person loses every role and cannot sign in again." %}
  • {% blocktrans trimmed %} It applies to their QGIS account, so it holds across every QGIS site, not only this one. {% endblocktrans %}
  • {% blocktrans trimmed %} Everybody they invited is suspended, and everybody those people invited, all the way down. {% endblocktrans %}
  • {% blocktrans trimmed %} Their published news items stay up and are still credited to them. Nothing is deleted. {% endblocktrans %}
  • {% blocktrans trimmed %} Anything of theirs waiting to be published goes back to draft, so it cannot go out without somebody looking at it again. {% endblocktrans %}

After that, getting access back means being invited again. {% plural %} A maintainer can undo the whole thing in one action for {{ counter }} days afterwards. After that, getting access back means being invited again. {% endblocktrans %}

{% trans "My account says suspended" %}

{% blocktrans trimmed %} Suspended is not the same as withdrawn. It means the person who vouched for you lost their access, so yours is paused while somebody looks at it. You have not done anything wrong. {% endblocktrans %}

{% blocktrans trimmed %} You can still sign in and read, but you cannot change anything. Your work is untouched. Ask a feed maintainer, who can either put it back or find you a new sponsor. {% endblocktrans %}

{% trans "I cannot sign in" %}

{% trans "There are three common reasons." %}

{% trans "You need an invitation" %}
{% blocktrans trimmed %} Your QGIS account works, but there is no account for you on this site yet. Ask a feed maintainer to invite you, and tell them the QGIS account name you signed in with. {% endblocktrans %}
{% trans "You do not have access to that page" %}
{% blocktrans trimmed %} You are signed in, but your role does not cover that page. Sign out and in again first, because roles are refreshed at each sign in. If it still will not open, ask a feed maintainer to check your role. {% endblocktrans %}
{% trans "Too many sign in attempts" %}
{% blocktrans trimmed %} Wait a few minutes and try again. We slow repeated attempts down to keep accounts safe. {% endblocktrans %}

{% blocktrans trimmed %} Anything else, ask a feed maintainer. Creating roles, changing what a role is allowed to do, and setting up the account service are jobs for them. {% endblocktrans %}
